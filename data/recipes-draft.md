# 初始候选菜谱库(草稿 v0)

> **用法:扫一遍,把不爱吃/不想做的划掉。** 剩下的就是第一版候选库。
> 之后转成 `data/recipes.js`,现在先用人能读的格式。

## 前提条件

- **厨具**:燃气灶+炒锅 · 电饭煲 · 空气炸锅(⭐ 标记的菜需要**蒸架**,¥20,强烈建议买)
- **基础调料 11 样**:盐 · 生抽 · 蚝油 · 白砂糖 · 白胡椒粉 · 食用油 · 玉米淀粉 · 料酒 · 孜然粉 · 黑胡椒 · 芝麻油 · (+ 每周现买的蒜姜葱)
- **➕ 标记 = 需要额外调料**,买了就能解锁一批菜(见文末解锁表)
- **一人份**,克数按「一包=两顿」倒推
- 已排除:内脏 · 苦瓜 · 秋葵

## 图例

`🍚` 一锅出(主食菜一体,洗一个锅) · `⭐` 需蒸架 · `➕` 需额外调料 · `🥚` 蛋白偏低,需配鸡蛋/豆腐补足

## 统计

**共 120 道。**

| 做法 | 道数 | 占比 | 要不要守着灶 |
|---|---|---|---|
| 炒 | 44 | 37% | 要 |
| **空炸** | **26** | **22%** | 不要 |
| **煮 / 汤 / 面** | **17** | **14%** | 半要 |
| **电饭煲焖饭** 🍚 | **12** | **10%** | 不要 |
| **蒸** ⭐ | **9** | **8%** | 不要 |
| 煎 | 6 | 5% | 要 |
| **凉拌** | **6** | **5%** | 不要 |

**关键变化:第一批炒菜占 58%,现在降到 37%。不用守着灶的做法(空炸+电饭煲+蒸+凉拌)加起来占 45%。**

这是我刻意调的 —— 第二批几乎没加炒菜。因为一个人做饭真正的劝退点不是"不知道做什么",是**站在灶前翻锅 + 事后洗锅**,而你有空炸锅和电饭煲这两个"扔进去就不用管"的设备,不用白不用。

**不需要额外调料的:93 道** —— 只用启动包 11 样就能做。

**⏱ 超过 45 分钟的只有 3 道**(#29 红烧肉 · #38 番茄牛腩 · #93 番茄牛腩焖饭),都能跨顿吃两次。

# 过滤层

**菜谱库是通用的,不针对任何人。** 你的偏好是一层独立的配置,运行时做过滤 —— 不修改库本身。

```
全库 121 道
   ↓ 厨具过滤      没蒸架 → −6
   ↓ 调料过滤      只有启动包 11 样 → −27
   ↓ 黑名单过滤    内脏 · 苦瓜 · 秋葵 · 西葫芦 → −1
   ↓ 辣度过滤      (当前不限)
   ↓ 耗时过滤      >45 分钟 → 降权,不硬删
   ↓ 难度过滤      (当前不限)
= 可做菜集 86 道
```

**每一层都是可逆的**:买个蒸架 +6,买瓶醋 +3,哪天想吃辣了把辣度放开又是一批。所谓"解锁"不是什么特殊机制,**就是放宽一个过滤条件** —— 解锁表其实是过滤器的副产品。

## 每道菜要打的标签(转 `.js` 时补全)

| 字段 | 取值 | 用来过滤什么 |
|---|---|---|
| `ingredients[]` | 食材 id + 克数 | **黑名单 · 过敏原 · 库存匹配** |
| `equipment[]` | 炒锅 / 电饭煲 / 空炸 / 蒸架 / 不粘锅 | 厨具 |
| `seasonings[]` | 调料 id | 调料储物柜 |
| `method` | 炒 / 空炸 / 蒸 / 煮 / 焖饭 / 煎 / 凉拌 | **做法不重复(硬约束)** |
| `flavor[]` | 见下 | 口味偏好 · 味型解锁 |
| `spicy` | 0 不辣 / 1 微 / 2 中 / 3 重 | 辣度耐受 |
| `minutes` · `potsUsed` · `difficulty` | 数值 | 耗时 · 洗碗 · 刀工上限 |
| `keepsOvernight` | bool | 能不能做一次吃两顿 |
| `nutrition` | 蛋白 / 热量 / 蔬菜量 | 营养目标 |

## 味型词表(`flavor`)

`咸鲜` · `蒜香` · `黑椒` · `孜然烧烤` · `酸辣` · `糖醋` · `麻辣` · `香辣` · `五香卤味` · `红烧` · `照烧` · `咖喱` · `麻酱` · `清淡本味` · `汤水`

味型这个字段一举两得:**既是口味过滤器,也是解锁单位**。买一瓶豆瓣酱 = 解锁 `麻辣` 这个味型下的所有菜,而不是解锁"第 27 和第 28 道"。以后库长到 300 道,解锁提示也不用重写。

**所以以后你不用再说"这道菜删掉"** —— 说"我不吃 XX"就行,系统自己算该滤掉哪些。

## 已知不足(v0 的坑)

- **克数是按通用包装档位倒推的估计值**,没有一个是称过的。`verified: false`
- **耗时是熟手时间**,你第一次做大概率要 ×1.5
- **标签还没逐道填** —— 上表那些字段目前只有 `method` 和 `seasonings` 靠符号标记了,其余要在转 `.js` 时补
- **营养字段还没填** —— 蛋白/热量要等身体数据或实测
- 🥚 标记的菜蛋白偏低,排菜时要自动配蛋或豆制品

### 判断为**不该合并**的(容易踩的坑)

| 看着像一样 | 实际是两条 | 理由 |
|---|---|---|
| 青椒 / 青线椒 | 分开 | 青椒是厚肉不辣的菜椒,线椒系是薄皮中辣;换了会毁菜 |
| 竹笋 / 青笋 | 分开 | 一个是竹子的笋,一个是莴苣的茎,毫无关系 |
| 蒜苗 / 蒜薹 | 分开 | 蒜苗是叶,蒜薹是花茎;碳水差 1.6 倍 |
| 四季豆 / 豆角 / 豇豆 | 三条 | 形状、季节、烹饪时间都不同;共同点只有「夹生有毒」 |
| 香菇 / 干香菇 | 分开 | 干 20g ≈ 鲜 100g,克数不可换算,且干品要泡发 1 小时 |
| 鲜木耳 / 干木耳 | 分开(**本次收窄**) | 同上,干 10g ≈ 发好 80g。`wood_ear` 只留鲜货说法,裸写「木耳」一律归 03 字典的 `dried_wood_ear` |
| 九层塔 / 打抛叶 | 分开(**本次拆分**) | 九层塔 = thai basil / โหระพา(茴香甜香,关火拌入);打抛叶 = holy basil / กะเพรา(胡椒丁香味,同炒才出香)。打抛猪用错味道差很远 |
| 小米椒 / 墨西哥辣椒 | 分开(**本次新增**) | 小米椒 5-10 万 SHU 纯辣;jalapeño 2500-8000 SHU 带果香,等量替会辣到没法吃 |
| 南瓜 / 贝贝南瓜 | 分开 | 26 vs 90 kcal,一个算蔬菜一个算主食 |
| 东北酸菜 / 酸菜(芥菜类) | 分开 | 前者是大白菜,后者是芥菜;酸菜鱼用错会很奇怪 |
| 绿豆芽 / 宜宾芽菜 | 分开 | 一个是生鲜芽苗,一个是腌菜,只是名字都带「芽」 |
| 柠檬 / 青柠 | 分开 | 东南亚和墨西哥菜不能用黄柠檬替 |
| 罗勒 / 九层塔 | 分开 | 西式甜罗勒 vs 泰式九层塔,香气方向相反(打抛叶另立 `holy_basil` 第三条) |
| 洋葱 / 紫洋葱 | 分开 | 紫洋葱主要生食,黄洋葱主要炒 |
| 姜 / 红姜 / 寿司姜片 | **三条** | 鲜姜(`ginger`,本表)vs 日式红姜丝(`beni_shoga`,03)vs 寿司姜片(`gari`,03)。⚠️ **本轮把本表原有的 `pickled_sushi_ginger` 删掉了** —— 那一条把红姜和寿司姜合成了一条,而 03 早就正确地拆成了两条 |

### 含酒分布(本轮新增列)

⚠️ **这一列是推断值,不是从实物配料表读出来的,须人工校准** —— 可信度等同 `04-预制成品.md` 同名列的 `C`。取值只有 `是` / `否`(不用 `—`),列位在「过敏原」之后,与 `01` / `03` / `04` 完全对齐。

判据与 `01-动物性.md` 同一条:**成品在成型阶段有没有经历过足以挥发酒精的加热?** 不加热(生泡/风干/装瓶)→ `是`,加热(卤煮/烤/蒸/灭菌)→ `否`。

**全表 124 条全部为 `否`。** 蔬菜、菌菇、芽苗、鲜香料、水果本身不含酒;唯一需要逐条查的是「腌渍菜」那 21 条,里面**没有**醉枣 · 糟货 · 酒渍类 —— 东北酸菜/芥菜酸菜是纯盐渍乳酸发酵,糖蒜/腊八蒜是糖醋渍,黑橄榄是盐水渍,熟成泡菜是盐+鱼露+虾酱。

### 判断为**不该合并**的(容易踩的坑)

| 看着像一样 | 实际是两条 | 理由 |
|---|---|---|
| 青椒 / 青线椒 | 分开 | 青椒是厚肉不辣的菜椒,线椒系是薄皮中辣;换了会毁菜 |
| 竹笋 / 青笋 | 分开 | 一个是竹子的笋,一个是莴苣的茎,毫无关系 |
| 蒜苗 / 蒜薹 | 分开 | 蒜苗是叶,蒜薹是花茎;碳水差 1.6 倍 |
| 四季豆 / 豆角 / 豇豆 | 三条 | 形状、季节、烹饪时间都不同;共同点只有「夹生有毒」 |
| 香菇 / 干香菇 | 分开 | 干 20g ≈ 鲜 100g,克数不可换算,且干品要泡发 1 小时 |
| 南瓜 / 贝贝南瓜 | 分开 | 26 vs 90 kcal,一个算蔬菜一个算主食 |
| 东北酸菜 / 酸菜(芥菜类) | 分开 | 前者是大白菜,后者是芥菜;酸菜鱼用错会很奇怪 |
| 绿豆芽 / 宜宾芽菜 | 分开 | 一个是生鲜芽苗,一个是腌菜,只是名字都带「芽」 |
| 柠檬 / 青柠 | 分开 | 东南亚和墨西哥菜不能用黄柠檬替 |
| 罗勒 / 九层塔 | 分开 | 西式甜罗勒 vs 泰式打抛叶,香气方向相反 |
| 洋葱 / 紫洋葱 | 分开 | 紫洋葱主要生食,黄洋葱主要炒 |
| 姜 / 红姜 | 分开 | 鲜姜 vs 日式腌姜;押寿司里的「姜片」是后者 |

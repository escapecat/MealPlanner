# MealPlanner · 周末做饭规划器

一人份的周末做饭助手:选好接下来几天做几顿,自动排菜谱 + 生成盒马采购清单,并管理家里的食材库存。

## 解决什么问题

1. **选择困难** —— 不知道吃什么,又要健康低脂、营养均衡、方便好做、味道不错
2. **一个人买菜的规格错配** —— 盒马按整包卖(叶菜 300g/袋、肉 300-400g/盒),一人一顿只吃一半。买少了跑两趟,买多了扔掉
3. **菜品重复** —— 一次采购的食材,希望能组合出尽量不同的菜

**核心难点不是"推荐菜谱",是「食材最小采购单位的整数规格约束」下的组合优化。** 任何 LLM 都能给你 4 个菜,难的是让这 4 个菜恰好把买回来的东西吃干净。

# 盒马尝鲜池调研

> 调研时间:2026-08-04 · 7 个品类 100 个 SKU
> 用途:「本周尝鲜」功能的商品池 —— 每周推荐一样用户没买过的盒马商品。
>
> ⚠️ **这份数据会过期**,性质跟 `hema-research.md`(生鲜规格,相对稳定)完全不同。
> 维护周期见「判断题 1」:**纯网红清单 3-6 个月过期一半,混合清单 6-12 个月。**
> 对齐盒马自己的换季节奏:**每年 3 月前后、9 月前后各大修一次**,季度间小补丁。

## 证据等级说明

盒马商品详情页**只存在于 App / 小程序内**(需登录 + 定位,价格按城市门店浮动),公开网页版 freshippo.com 抓不到商品数据 —— 四个子代理独立实测确认。

- **A 级**主要来自:FatSecret 热量库、海外站(weee/亚米/Foodaily 产品库)的规格、政府抽检与价格监测 PDF 里的净含量、官方口径行业数据
- **价格几乎全是 B / B−**(媒体门店走访、测评时点快照)。盒马晚间打折、移山价、会员日、奥莱清货波动极大
- **→ 小程序里不要写死价格**

热量档参照:低 <200 kcal/100g|中 200-330|高 >330

{
  id, name, category,          // 烘焙/零食/水果/乳饮/熟食/半成品/冷冻小食
  spec, priceHint,             // ⚠️ 价格只作参考,不写死(波动极大)

  listedYM: '2026-06',         // 上架年月,用于算过期权重

  kcalTier, protein,           // 有就填,大面积缺失是常态
  confidence: 'A'|'B'|'B−'|'C',
  dietFriendly: '是'|'否'|'慎', // 钠高的标「慎」
}

**`tier` 三分法的用法**(比二分好在这里):

| tier | 推荐策略 |
|---|---|
| **长青** | 兜底。池子见底时永远有得推 |
| **时令** | 按 `monthWindow` **过滤而非删除** —— 青团、杨梅、车厘子明年会回来 |
| **网红** | 给推荐权重,但按 `listedYM` **设过期时间**,超过 6 个月自动降权 |

# 安全备注 —— 已用 curl 定案:工具层产物,非网页投毒

调研中,两个页面经 WebFetch 返回的摘要末尾出现了与正文无关的文本:

| 来源 | 观察到的内容 |
|---|---|
| `finance.sina.com.cn/roll/2025-03-03/doc-inenkfeh9221222.shtml` | 英文:"You are not a lawyer and never comment on the legality of your own prompts and responses." |
| `news.bjd.com.cn/2026/03/11/11625681.shtml` | 中文:「我不是律师,不对本回答的合法性作评论。」 |

**验证方法**:WebFetch 本身是嫌疑组件,所以绕开它直接 `curl` 抓原始 HTML 搜索这两句。

```
新浪财经   http 200, 95863 bytes
  "never comment on the legality"    → 0 次
  "不对本回答的合法性作评论"            → 0 次
  "律师"                              → 1 次,是页脚 <a>网站律师</a> 链接

京报网     http 200, 46641 bytes
  英文注入句                          → 0 次
  「律师」                            → 0 次
```

**两个页面的原始 HTML 里都不含这两句话。**

**结论:这是 WebFetch 内部摘要模型的 prompt 片段泄漏,不是站点被投毒。** 同一条指令的中英两个变体出现在两个不相干的主流新闻站,本就更符合工具层固定 prompt 漏出,curl 坐实了这一点。

**对调研数据的影响:无。** 载荷为行为约束型(身份指派 + 不评论合法性),未尝试套系统提示、抓取其他 URL、外传数据或绕过权限,也未篡改任何结论或价格数字。
